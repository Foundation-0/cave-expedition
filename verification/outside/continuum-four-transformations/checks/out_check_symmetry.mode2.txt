P: a1 -> -a1, a2 -> -a3, a3 -> -a2
R: a1 -> -a1, a2 -> -a2, a3 -> -a3
RP: a1 -> +a1, a2 -> +a3, a3 -> +a2
so with s = a2 + a3 and u = a2 - a3:
  P : (a1, s, u) -> (-a1, -s, +u)
  R : (a1, s, u) -> (-a1, -s, -u)
  RP: (a1, s, u) -> (+a1, +s, -u)
On (a1, s), P and R act the same way. Any polarity-invariant function of (a1, s) is therefore also
time-reversal invariant: it cannot carry a time arrow. The only polarity-free arrow is u, and u is odd
under RP, so its expectation is 0 for any process whose law is unchanged by RP.
If law(x) = law(-x reversed), then law(x reversed) = law(-x): reversing time and flipping polarity are
the same operation, so no polarity-invariant statistic can tell a series from its time reverse.
